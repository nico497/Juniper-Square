How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one for a private equity or real estate fund manager, Juniper Square or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), logged out of ChatGPT so there's no memory or personalization.
  • Open comparison question: "Juniper Square vs. {rival}: which should I choose?" Asked once per order (12 answers) — this is where the qualitative reasoning and citations below come from. It is not repeated, so a single odd answer could be noise. One run (SS&C GlobalOps, rival named first) drifted into a career/job comparison rather than a software one — flagged where it appears.
  • Both orders are asked because ChatGPT can lean toward whichever brand is named first. For Carta, SS&C GlobalOps, AppFolio Investment Manager, InvestNext and Agora it doesn't matter — Juniper Square sweeps 10 of 10 either way. For Allvue Systems, the result varies: Juniper Square sweeps when named first, but Allvue wins 4 of 5 when named first instead — that's a real, not just order-driven, closeness.
  • Not yet covered: pricing, integrations, onboarding, setup and support as separate scored dimensions — they'd need their own repeated, structured prompts to be real rather than invented. Also not covered: any engine besides ChatGPT, and any run while logged in.
